# Security

If you find a security problem in Serviceform AgenticSearch, please do not open a public issue. Write to support@serviceform.com with what you found and how to reproduce it. We will confirm we have it and tell you what happens next.

The search tool id used in the SDK is a public identifier, not a secret. Please do report anything that lets one site read another site's data, or that runs script from search results or settings.
